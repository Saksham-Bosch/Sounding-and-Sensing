# Test Asset Policy

Sample inputs for the live tests live under `tests/assets/private/`:

- `sample_audio.mp3`
- `sample_video.mp4`
- `sample_document.pdf`

- Files in `private/` are ignored by git (also matched by extension in `.gitignore`).
- Do not use customer, employee, production, or confidential content.
- Do not commit extracted text or generated output derived from these files.
