# Contributing

This repository is intended for disciplined, reviewable changes.

- Never commit secrets, user uploads, or local workbooks.
- Use feature or phase branches for all work after the initial scaffold.
- Keep integrations behind interfaces.
- Add tests with implementation changes.
- Update relevant documentation.
- Do not introduce Speech-to-Text or OCR models without approval.
- Do not introduce open-source dependencies without license and security review.
- Use clear, scoped commits.

Preferred workflow:

1. Read the architecture and repository instructions first.
2. Make the smallest coherent change.
3. Validate the change locally.
4. Commit only the intended files.
5. Keep proposed and implemented behavior clearly separated in documentation.
